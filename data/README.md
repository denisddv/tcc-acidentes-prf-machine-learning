# Dados

Este diretório é reservado aos dados utilizados no projeto.

## raw/
Arquivos anuais originais da PRF, baixados pelo notebook de coleta. Eles não são versionados no Git por tamanho e por serem reproduzíveis a partir da fonte pública.

## processed/
Bases intermediárias e tratadas, incluindo a base consolidada e a camada Silver. Também não são versionadas.

O pipeline completo de geração dessas bases será mantido nos notebooks do projeto.
